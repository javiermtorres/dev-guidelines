# General code guidelines

* Use English for comments and code constructs
* Try to reuse code that repeats more than five lines in more than two places
* Split up functions of more than a page or so in length
* After writing all the code, make a review and check these guidelines again. Repeat until the code is good enough, noting the places where this could not be achieved after three passes.
* Finally, always, when uncertainty is high, stop the task and notify the issue with possible ways ahead.
