# Code review

* Write as concisely and clearly as possible.
* Check the code guidelines for the language used and make sure they are followed.
* Propose alternatives to the code that are more efficient, readable, or maintainable.
* Write first a report with all comments. Then, if it is a PR in a github repository, ask the user if you should create comments in the reviewed PR. In any case, provide a patch file with the proposed changes.
